# Тестовое задание: Мини API для списка задач.

## Цель
Нужно реализовать небольшой REST API на NestJS/FastAPI для работы со списком

## Что нужно сделать

Создай приложение с двумя endpoint’ами:

### POST /tasks - Создает новую задачу.
Тело запроса:

```json
{
"title": "Купить молоко"
,
"description": "2 литра"
,
"status": "new"
}
```

Поля:

- title — обязательное, строка
- description — необязательное, строка
- status — обязательное, одно из значений: new, in_progress, done

Ответ:

созданная задача с id

Пример ответа:

```json
{
"id": 1,
"title": "Купить молоко"
,
"description": "2 литра"
,
"status": "new"
}
```
### GET /tasks - Возвращает список всех задач.
Пример ответа:

```json
{
"id": 1,
"title": "Купить молоко"
,
"description": "2 литра"
,
"status": "new"
}
```

## Условия

- Использовать FastAPI/Pydantic
- Хранение данных можно сделать в памяти массива, без базы данных
- Добавить валидацию входящих данных
- Разделить код по базовой структуре NestJS:
-- controller
-- service
-- dto

## Что будет плюсом

Не обязательно, но будет преимуществом:

- добавить GET /tasks/:id
- обработать случай, когда задача не найдена
- использовать class-validator
